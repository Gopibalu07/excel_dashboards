# 📊 Swiggy Sales & Customer Insights Dashboard (Excel)

## 🔍 Overview

This project is an interactive Excel dashboard built to analyze sales performance, customer behavior, and regional trends in a food delivery dataset. The goal is to extract actionable insights that can support business decisions.

---

## 📁 Dataset

* Food delivery dataset (Swiggy-like data)
* Includes orders, revenue, ratings, cities, and restaurant details
* Data was cleaned and structured before analysis

---

## ⚙️ Workflow

1. Data Cleaning (handling missing values and formatting)
2. Data Transformation (creating KPIs and calculated fields)
3. Data Analysis using Pivot Tables
4. Dashboard Design with interactive filters

---

## 📊 Dashboard Features

* KPI Cards (Total Sales, Avg Order Value, Ratings, Total Orders)
* Monthly, Weekly, and Daily Sales Trends
* City-wise Sales Analysis (Top-performing cities)
* State-wise Sales Distribution (Map visualization)
* Food Type Analysis (Veg vs Non-Veg)
* Interactive Filters (Month, State, Restaurant Name)

---

## 📈 Key Insights

* Non-Veg orders contribute ~67% of total sales
* Bengaluru is the highest revenue-generating city
* Sales patterns show higher activity during weekends
* Stable sales trend with periodic peaks across months
