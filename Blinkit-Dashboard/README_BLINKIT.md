# 📊 BlinkIT Sales Dashboard (Excel Project)

## 🔍 Overview

This project presents an interactive Excel dashboard built using a real-world BlinkIT grocery dataset. The dashboard focuses on analyzing sales performance, product trends, and outlet-level insights to support business decision-making.

---

## 📁 Dataset

* E-commerce grocery dataset (BlinkIT)
* Includes product categories, outlet types, sales values, and ratings
* Data was cleaned and structured before analysis

---

## ⚙️ Workflow

1. Data Cleaning (handling inconsistencies and formatting)
2. Data Transformation (creating KPIs and calculated metrics)
3. Data Analysis using Pivot Tables
4. Dashboard Design with interactive slicers

---

## 📊 Dashboard Features

* KPI Cards (Total Sales, Avg Sales, Total Items, Avg Rating)
* Sales Trend Analysis (Year-wise)
* Category-wise Sales Breakdown
* Outlet Size & Location Analysis
* Item Type Performance
* Interactive Filters (Outlet Size, Location Type, Item Type)

---

## 📈 Key Insights

* Tier 3 outlets contribute the highest revenue
* Fruits & Vegetables and Snack Foods are top-performing categories
* Low-fat products dominate overall sales (~65%)
* Sales showed steady growth, peaking around 2018
